# Working on Augur Website

Before any change, read the [documentation index](docs/README.md), [CONTRIBUTING.md](CONTRIBUTING.md) and the [conventions](docs/reference/conventions.md). They hold the rules for every contributor; this file adds only what applies to agents.

- Keep changes within the request and preserve unrelated work.
- A claim is verified when you have checked it against its source in the current session: a file, command output, or a live check. Do not run tests unless requested.
- Start the dev server in background mode, as in the [README](README.md#setup). Use package scripts if available.

## Working with Astro

Use the official Astro Docs MCP at `https://mcp.docs.astro.build/mcp` for task-specific Astro documentation.

If the Astro Docs MCP tools are unavailable, tell the user and give the endpoint. Setup guide: [Astro AI guides](https://docs.astro.build/en/guides/build-with-ai/).
