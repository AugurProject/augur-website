# Maintaining documentation

These rules apply only to documentation under `docs/` and supplement the repository-wide rules in [../AGENTS.md](../AGENTS.md).

Before writing or editing documentation, read and follow the shared guidance in [README.md](README.md).

## Index maintenance

Update the index when adding, renaming or removing documentation.

## Verification

Check affected links, file paths, commands and references against their sources. Report anything you could not verify. Documentation-only changes do not require builds or tests.

## External references (temporary)

Link an external source only when it is needed to verify a documented fact, and link the minimum needed. Ask the owner before adding any external link not already in the reference set in [design-sources.md](design-sources.md). Remove this section once the owner approves a standing reference policy.
