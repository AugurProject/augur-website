## Content and organization

Keep each document short, scoped and actionable.
Update documentation when the facts or approved decisions it describes change.
Preserve unresolved decisions and verification limits.
Link to existing guidance rather than repeating it.

Keep this README as a reader-facing index and shared writing guide. Index entries
describe what each document covers and when to read it. Agent maintenance
instructions belong in [AGENTS.md](AGENTS.md).

## Writing style

Write direct, concrete language with focused sentences. Preserve exact technical
terms, filenames and commands. Distinguish confirmed behavior, assumptions, plans
and verification limits. Include rationale when it explains a useful constraint
or decision; remove filler and repetition. These are lightweight writing
principles, not formal ASD-STE100 compliance or imitation of an author's style.
